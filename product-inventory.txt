Product Inventory API Documentation
===================================

Base URL
--------
https://drba7rerp-production.up.railway.app

---------------------------------------------------------
PRODUCT INVENTORY APIs
---------------------------------------------------------

1) Create Product Inventory Record
   Method: POST
   URL: /prodcut-inventory/inventory/:inventoryId
   Description: Associates a product with an inventory branch along with quantity and cost price.

   Path Parameters:
   - inventoryId: required string (ID of the inventory)

   Validation Rules:
   - productId: required string
   - quantity: required number, minimum 0
   - costPrice: required number, minimum 0
   - inventoryId: optional string

   Request Example:
   {
     "productId": "cm4product123",
     "quantity": 100,
     "costPrice": 12.5
   }

   Response Example (201 Created):
   {
     "message": "Product inventory created successfully",
     "productInventory": {
       "id": "cm4prodinv123",
       "productId": "cm4product123",
       "inventoryId": "cm4inventory123",
       "quantity": 100,
       "costPrice": 12.5,
       "deletedAt": null
     }
   }

   Error Responses:
   - 404 Not Found:
     {
       "statusCode": 404,
       "message": "Inventory not found",
       "error": "Not Found"
     }
   - 404 Not Found:
     {
       "statusCode": 404,
       "message": "Product not found",
       "error": "Not Found"
     }
   - 400 Bad Request:
     {
       "statusCode": 400,
       "message": "Product inventory already exists",
       "error": "Bad Request"
     }

4) Update Product Inventory Record
   Method: PATCH
   URL: /prodcut-inventory/:id
   Description: Updates quantity and/or cost price for a product inventory record.

   Path Parameters:
   - id: required string

   Request Example:
   {
     "quantity": 150,
     "costPrice": 13.0
   }

   Response Example (200 OK):
   {
     "message": "Product inventory updated successfully",
     "productInventory": {
       "id": "cm4prodinv123",
       "productId": "cm4product123",
       "inventoryId": "cm4inventory123",
       "quantity": 150,
       "costPrice": 13,
       "deletedAt": null
     }
   }

   Error Response:
   - 404 Not Found:
     {
       "statusCode": 404,
       "message": "Product inventory with ID cm4prodinv123 not found",
       "error": "Not Found"
     }

5) Delete Product Inventory Record (Soft Delete)
   Method: DELETE
   URL: /prodcut-inventory/:id
   Description: Soft-deletes a product inventory record (sets deletedAt timestamp).

   Path Parameters:
   - id: required string

   Example Request:
   DELETE /prodcut-inventory/cm4prodinv123

   Response Example (200 OK):
   {
     "message": "Product inventory deleted successfully"
   }

   Error Response:
   - 404 Not Found:
     {
       "statusCode": 404,
       "message": "Product inventory with ID cm4prodinv123 not found",
       "error": "Not Found"
     }
