App API Documentation
=====================

Base URL
--------
http://localhost:3000

---------------------------------------------------------
BRANCH APIs
---------------------------------------------------------

1) Create Branch
   Method: POST
   URL: /branch
   Description: Creates a new branch.

   Validation Rules:
   - name: required string, minimum 2 characters
   - code: required string, minimum 2 characters
   - address: optional string

   Request Example:
   {
     "name": "فرع القاهره",
     "code": "CAI-001",
     "address": "القاهره، وسط البلد"
   }

   Response Example:
   {
     "data": {
       "id": "cm4branch123",
       "name": "فرع القاهره",
       "code": "CAI-001",
       "address": "القاهره، وسط البلد",
       "createdAt": "2026-08-07T00:00:00.000Z",
       "updatedAt": "2026-08-07T00:00:00.000Z",
       "deletedAt": null
     },
     "message": "Branch created successfully"
   }

2) Get All Branches
   Method: GET
   URL: /branch
   Description: Returns all active (not deleted) branches.
   Response Example:
   {
     "data": [
       {
         "id": "cm4branch123",
         "name": "فرع القاهره",
         "code": "CAI-001",
         "address": "القاهره، وسط البلد",
         "createdAt": "2026-08-07T00:00:00.000Z",
         "updatedAt": "2026-08-07T00:00:00.000Z",
         "deletedAt": null
       },
       {
         "id": "cm4branch456",
         "name": "فرع اسكندريه",
         "code": "ALX-001",
         "address": "الاسكندريه، محطة الرمل",
         "createdAt": "2026-08-07T01:00:00.000Z",
         "updatedAt": "2026-08-07T01:00:00.000Z",
         "deletedAt": null
       }
     ],
     "message": "All branches returned successfully"
   }

3) Get Branch By ID
   Method: GET
   URL: /branch/:id
   Description: Returns one branch by its id.

   Example Request:
   GET /branch/cm4branch123

   Response Example:
   {
     "data": {
       "id": "cm4branch123",
       "name": "فرع القاهره",
       "code": "CAI-001",
       "address": "القاهره، وسط البلد",
       "createdAt": "2026-08-07T00:00:00.000Z",
       "updatedAt": "2026-08-07T00:00:00.000Z",
       "deletedAt": null
     },
     "message": "Branch returned successfully"
   }

   Error Response (if not found):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found"
   }

4) Update Branch
   Method: PATCH
   URL: /branch/:id
   Description: Updates a specific branch partially.

   Request Example:
   {
     "name": "فرع القاهره المحدث"
   }

   Response Example:
   {
     "data": {
       "id": "cm4branch123",
       "name": "فرع القاهره المحدث",
       "code": "CAI-001",
       "address": "القاهره، وسط البلد",
       "createdAt": "2026-08-07T00:00:00.000Z",
       "updatedAt": "2026-08-07T02:00:00.000Z",
       "deletedAt": null
     },
     "message": "Branch updated successfully"
   }

5) Delete Branch
   Method: DELETE
   URL: /branch/:id
   Description: Soft-deletes a branch (sets deletedAt timestamp).

   Response Example:
   {
     "message": "Branch deleted successfully"
   }

INVENTORY APIs
---------------------------------------------------------

1) Create Inventory By Branch ID
   Method: POST
   URL: /inventory/branch/:branchId
   Description: Creates a new inventory linked to a specific branch.

   Validation Rules:
   - name: required string, minimum 2 characters
   - address: required string, minimum 2 characters

   Request Example:
   POST /inventory/branch/cm4branch123
   {
     "name": "مخزن القاهره",
     "address": "القاهره، المنطقة الصناعية"
   }

   Response Example:
   {
     "data": {
       "id": "cm4inventory789",
