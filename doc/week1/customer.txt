Customer API Documentation
==========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see 00-overview.txt)
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

NOTE: money fields are sent as numbers but returned as strings ("1500").
      Max 2 decimal places (1500.255 -> 400, it is never rounded).

openingBalance sign (رصيد أول المدة)
------------------------------------
    + positive  = the CUSTOMER owes us   (مدين - على العميل لنا)
    - negative  = WE owe the customer    (دائن - للعميل علينا)
    0           = nothing (default)

Customer object (what "data" contains)
---------------------------------------
{
  "id": "cm4customer123",
  "code": "CUS-703669",               <-- generated by the server
  "name": "شركة التقنية الحديثة",

}

---------------------------------------------------------
CUSTOMER APIs
---------------------------------------------------------

1) Create Customer
   Method: POST
   URL: /customer

   Validation Rules:
   - name: required string
   - taxNumber: optional string
   - commercialRecord: optional string
   - phone: optional string
   - address: optional string
   - creditLimit: optional number, minimum 0, max 2 decimal places (default 0)
   - openingBalance: optional number, CAN BE NEGATIVE (see the sign table above),
                     max 2 decimal places (default 0)
     creditLimit / openingBalance: null -> 400 (send 0 instead)
   - code: do NOT send (generated by the server as "CUS-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "شركة التقنية الحديثة",
     "taxNumber": "300123456700003",
     "commercialRecord": "1010123456",
     "phone": "0501234567",
     "address": "الرياض، المملكة العربية السعودية",
     "creditLimit": 10000,
     "openingBalance": 1500
   }

   Response Example (201):
   {
     "message": "customer created successfully",
     "data": { ...customer object }
   }

   Error Response (400 - validation / unknown field):
   {
     "statusCode": 400,
     "message": ["name should not be empty", "name must be a string"],
     "error": "Bad Request",
     "code": "VALIDATION_FAILED",
     "field": "name"
   }

   Error Response (400 - more than 2 decimals):
   {
     "statusCode": 400,
     "message": ["creditLimit must have at most 2 decimal places"],
     "error": "Bad Request",
     "code": "VALIDATION_FAILED",
     "field": "creditLimit"
   }

2) Get All Customers
   Method: GET
   URL: /customer
   Description: All active (not deleted) customers, newest first.
                Empty list -> "data": []

   Response Example:
   {
     "message": "Customers returned successfully",
     "data": [ { ...customer object } ]
   }

3) Get Customer By ID
   Method: GET
   URL: /customer/:id

   Response Example:
   {
     "message": "Customer returned successfully",
     "data": { ...customer object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "customer does not exist",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

4) Update Customer
   Method: PATCH
   URL: /customer/:id
   Description: Partial update. Any field from Create (except code).
                null CLEARS a nullable field: taxNumber, commercialRecord,
                phone, address. null on name / creditLimit / openingBalance -> 400.

   Request Example:
   {
     "name": "شركة التقنية الحديثة المحدودة",
     "creditLimit": 20000,
     "openingBalance": -300,            <-- we owe the customer 300
     "address": null                    <-- clears the address
   }

   Response Example:
   {
     "message": "customer updated successfully",
     "data": { ...updated customer object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "customer not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

5) Delete Customer
   Method: DELETE
   URL: /customer/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "customer deleted successfully",
     "data": null
   }

   Error Response (404): same as Update.
