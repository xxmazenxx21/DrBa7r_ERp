Customer API Documentation
==========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication
--------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)

NOTE: creditLimit / openingBalance are sent as numbers but returned as strings.
NOTE: GET responses here are NOT wrapped in "data" - see each endpoint.

---------------------------------------------------------
CUSTOMER APIs
---------------------------------------------------------

1) Create Customer
   Method: POST
   URL: /customer

   Validation Rules:
   - name: required string
   - taxNumber: optional string
   - commercialRecord: optional string
   - phone: optional string
   - address: optional string
   - creditLimit: optional number, minimum 0 (default 0)
   - openingBalance: optional number (default 0)
   - code: do NOT send (generated by the server as "CUS-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "شركة التقنية الحديثة",
     "taxNumber": "300123456700003",
     "commercialRecord": "1010123456",
     "phone": "0501234567",
     "address": "الرياض، المملكة العربية السعودية",
     "creditLimit": 10000,
     "openingBalance": 1500
   }

   Response Example (201):
   {
     "message": "customer created successfully",
     "customer": {
       "id": "cm4customer123",
       "code": "CUS-703669",
       "name": "شركة التقنية الحديثة",
       "taxNumber": "300123456700003",
       "commercialRecord": "1010123456",
       "phone": "0501234567",
       "address": "الرياض، المملكة العربية السعودية",
       "creditLimit": "10000",
       "openingBalance": "1500",
       "createdAt": "2026-08-19T13:45:00.000Z",
       "updatedAt": "2026-08-19T13:45:00.000Z",
       "deletedAt": null
     }
   }

   Error Response (400 - validation, e.g. missing name):
   {
     "message": ["name should not be empty", "name must be a string"],
     "error": "Bad Request",
     "statusCode": 400
   }

2) Get All Customers
   Method: GET
   URL: /customer
   Description: All active (not deleted) customers.

   Response Example - a plain ARRAY (empty [] when there are none):
   [
     {
       "id": "cm4customer123",
       "code": "CUS-703669",
       "name": "شركة التقنية الحديثة",
       "taxNumber": "300123456700003",
       "commercialRecord": "1010123456",
       "phone": "0501234567",
       "address": "الرياض، المملكة العربية السعودية",
       "creditLimit": "10000",
       "openingBalance": "1500",
       "createdAt": "2026-08-19T13:45:00.000Z",
       "updatedAt": "2026-08-19T13:45:00.000Z",
       "deletedAt": null
     }
   ]


3) Get Customer By ID
   Method: GET
   URL: /customer/:id
   Description: Returns the customer object directly (no "data" wrapper).

   Example Request:
   GET /customer/cm4customer123

   Response Example:
   {
     "id": "cm4customer123",
     "code": "CUS-703669",
     "name": "شركة التقنية الحديثة",
     "taxNumber": "300123456700003",
     "commercialRecord": "1010123456",
     "phone": "0501234567",
     "address": "الرياض، المملكة العربية السعودية",
     "creditLimit": "10000",
     "openingBalance": "1500",
     "createdAt": "2026-08-19T13:45:00.000Z",
     "updatedAt": "2026-08-19T13:45:00.000Z",
     "deletedAt": null
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "customer does not exist",
     "error": "Not Found"
   }

4) Update Customer
   Method: PATCH
   URL: /customer/:id
   Description: Partial update.

   Request Example:
   {
     "name": "شركة التقنية الحديثة المحدودة",
     "creditLimit": 20000
   }

   Response Example:
   {
     "message": "customer updated successfully",
     "customer": {
       "id": "cm4customer123",
       "code": "CUS-703669",
       "name": "شركة التقنية الحديثة المحدودة",
       "taxNumber": "300123456700003",
       "commercialRecord": "1010123456",
       "phone": "0501234567",
       "address": "الرياض، المملكة العربية السعودية",
       "creditLimit": "20000",
       "openingBalance": "1500",
       "createdAt": "2026-08-19T13:45:00.000Z",
       "updatedAt": "2026-08-19T13:50:00.000Z",
       "deletedAt": null
     }
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "customer not found",
     "error": "Not Found"
   }

5) Delete Customer
   Method: DELETE
   URL: /customer/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "customer deleted successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "customer not found",
     "error": "Not Found"
   }
