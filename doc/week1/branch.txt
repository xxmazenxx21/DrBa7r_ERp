Branch API Documentation
========================

Base URL
--------
http://localhost:3000   (the backend runs on your machine with Docker, see README.md)

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see 00-overview.txt)
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

Branch object (what "data" contains)
------------------------------------
{
  "id": "cm4branch123",
  "name": "فرع القاهره",
  "code": "branch-190301",          <-- generated by the server
  "address": "القاهره، وسط البلد",
  "createdAt": "2026-08-07T00:00:00.000Z",
  "updatedAt": "2026-08-07T00:00:00.000Z",
  "deletedAt": null
}

---------------------------------------------------------
BRANCH APIs
---------------------------------------------------------

1) Create Branch
   Method: POST
   URL: /branch

   Validation Rules:
   - name: required string, minimum 2 characters
   - address: optional string
   - code: do NOT send (generated by the server as "branch-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "فرع القاهره",
     "address": "القاهره، وسط البلد"
   }

   Response Example (201):
   {
     "message": "Branch created successfully",
     "data": { ...branch object }
   }

2) Get All Branches
   Method: GET
   URL: /branch
   Description: All active (not deleted) branches, newest first.

   Response Example:
   {
     "message": "All branches returned successfully",
     "data": [ { ...branch object }, { ...branch object } ]
   }

3) Get Branch By ID
   Method: GET
   URL: /branch/:id

   Response Example:
   {
     "message": "Branch returned successfully",
     "data": { ...branch object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

4) Update Branch
   Method: PATCH
   URL: /branch/:id
   Description: Partial update. Fields: name (min 2 characters), address.
                "address": null CLEARS the address. null on name -> 400.

   Request Example:
   {
     "name": "فرع القاهره المحدث"
   }

   Response Example:
   {
     "message": "Branch updated successfully",
     "data": { ...updated branch object }
   }

   Error Response (404): same as Get Branch By ID.

5) Delete Branch
   Method: DELETE
   URL: /branch/:id
   Description: Soft delete (sets deletedAt). The branch disappears from lists.

   Response Example:
   {
     "message": "Branch deleted successfully",
     "data": null
   }

   Error Response (404): same as Get Branch By ID.
