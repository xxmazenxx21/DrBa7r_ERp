Branch API Documentation
========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication
--------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)

---------------------------------------------------------
BRANCH APIs
---------------------------------------------------------

1) Create Branch
   Method: POST
   URL: /branch
   Description: Creates a new branch. The code is generated by the server.

   Validation Rules:
   - name: required string, minimum 2 characters
   - address: optional string
   - code: do NOT send (generated by the server as "branch-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "فرع القاهره",
     "address": "القاهره، وسط البلد"
   }

   Response Example (201):
   {
     "data": {
       "id": "cm4branch123",
       "name": "فرع القاهره",
       "code": "branch-190301",
       "address": "القاهره، وسط البلد",
       "createdAt": "2026-08-07T00:00:00.000Z",
       "updatedAt": "2026-08-07T00:00:00.000Z",
       "deletedAt": null
     },
     "message": "Branch created successfully"
   }

2) Get All Branches
   Method: GET
   URL: /branch
   Description: Returns all active (not deleted) branches, newest first.

   Response Example:
   {
     "data": [
       {
         "id": "cm4branch123",
         "name": "فرع القاهره",
         "code": "branch-190301",
         "address": "القاهره، وسط البلد",
         "createdAt": "2026-08-07T00:00:00.000Z",
         "updatedAt": "2026-08-07T00:00:00.000Z",
         "deletedAt": null
       },
       {
         "id": "cm4branch456",
         "name": "فرع اسكندريه",
         "code": "branch-552710",
         "address": "الاسكندريه، محطة الرمل",
         "createdAt": "2026-08-07T01:00:00.000Z",
         "updatedAt": "2026-08-07T01:00:00.000Z",
         "deletedAt": null
       }
     ],
     "message": "All branches returned successfully"
   }

   If there are no branches: { "data": [], "message": "All branches returned successfully" }

3) Get Branch By ID
   Method: GET
   URL: /branch/:id

   Example Request:
   GET /branch/cm4branch123

   Response Example:
   {
     "data": {
       "id": "cm4branch123",
       "name": "فرع القاهره",
       "code": "branch-190301",
       "address": "القاهره، وسط البلد",
       "createdAt": "2026-08-07T00:00:00.000Z",
       "updatedAt": "2026-08-07T00:00:00.000Z",
       "deletedAt": null
     },
     "message": "Branch returned successfully"
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found"
   }

4) Update Branch
   Method: PATCH
   URL: /branch/:id
   Description: Partial update. Send only the fields to change (name, address).

   Request Example:
   {
     "name": "فرع القاهره المحدث"
   }

   Response Example:
   {
     "data": {
       "id": "cm4branch123",
       "name": "فرع القاهره المحدث",
       "code": "branch-190301",
       "address": "القاهره، وسط البلد",
       "createdAt": "2026-08-07T00:00:00.000Z",
       "updatedAt": "2026-08-07T02:00:00.000Z",
       "deletedAt": null
     },
     "message": "Branch updated successfully"
   }

   Error Response (404): same as Get Branch By ID.

5) Delete Branch
   Method: DELETE
   URL: /branch/:id
   Description: Soft delete (sets deletedAt). The branch disappears from lists.

   Response Example:
   {
     "message": "Branch deleted successfully"
   }

   Error Response (404): same as Get Branch By ID.
