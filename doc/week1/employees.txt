Employees API Documentation
===========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication
--------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)

Every employee belongs to one branch.

---------------------------------------------------------
EMPLOYEES APIs
---------------------------------------------------------

1) Create Employee
   Method: POST
   URL: /employees/branch/:branchId
   Description: Creates a new employee under a branch.

   Path Parameters:
   - branchId: required string (id from GET /branch)

   Validation Rules:
   - fullName: required string
   - nationalId: optional string (must be unique)
   - jobTitle: optional string
   - hireDate: optional string (ISO date, e.g. "2025-01-01" or "2025-01-01T00:00:00.000Z")
   - code: do NOT send (generated by the server as "EMP-XXXXXX"; ignored if sent)

   Request Example:
   POST /employees/branch/cm4branch123
   {
     "fullName": "أحمد محمد",
     "nationalId": "1234567890",
     "jobTitle": "مندوب مبيعات",
     "hireDate": "2025-01-01T00:00:00.000Z"
   }

   Response Example (201):
   {
     "data": {
       "id": "cm4employee123",
       "code": "EMP-918639",
       "fullName": "أحمد محمد",
       "nationalId": "1234567890",
       "branchId": "cm4branch123",
       "jobTitle": "مندوب مبيعات",
       "hireDate": "2025-01-01T00:00:00.000Z",
       "createdAt": "2026-08-19T14:45:00.000Z",
       "updatedAt": "2026-08-19T14:45:00.000Z",
       "deletedAt": null
     },
     "message": "Employee created successfully"
   }

   Error Response (404 - branch not found):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found"
   }

   Error Response (400 - national ID already used):
   {
     "statusCode": 400,
     "message": "Employee with national ID 1234567890 already exists",
     "error": "Bad Request"
   }

   Error Response (409 - national ID belongs to a DELETED employee; national
   IDs stay reserved even after delete):
   {
     "statusCode": 409,
     "message": "nationalId already exists",
     "error": "Conflict"
   }

2) Get All Employees By Branch
   Method: GET
   URL: /employees/branch/:branchId
   Description: All active (not deleted) employees of a branch, newest first.

   Response Example:
   {
     "data": [
       {
         "id": "cm4employee123",
         "code": "EMP-918639",
         "fullName": "أحمد محمد",
         "nationalId": "1234567890",
         "branchId": "cm4branch123",
         "jobTitle": "مندوب مبيعات",
         "hireDate": "2025-01-01T00:00:00.000Z",
         "createdAt": "2026-08-19T14:45:00.000Z",
         "updatedAt": "2026-08-19T14:45:00.000Z",
         "deletedAt": null
       }
     ],
     "message": "Employees returned successfully"
   }

   Error Response (404 - branch not found):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found"
   }

3) Get Employee By ID
   Method: GET
   URL: /employees/:id

   Response Example:
   {
     "data": {
       "id": "cm4employee123",
       "code": "EMP-918639",
       "fullName": "أحمد محمد",
       "nationalId": "1234567890",
       "branchId": "cm4branch123",
       "jobTitle": "مندوب مبيعات",
       "hireDate": "2025-01-01T00:00:00.000Z",
       "createdAt": "2026-08-19T14:45:00.000Z",
       "updatedAt": "2026-08-19T14:45:00.000Z",
       "deletedAt": null
     },
     "message": "Employee returned successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "Employee with id cm4employee123 not found",
     "error": "Not Found"
   }

4) Update Employee
   Method: PATCH
   URL: /employees/:id
   Description: Partial update.

   Validation Rules (all optional):
   - fullName: string
   - nationalId: string
   - jobTitle: string
   - hireDate: ISO date string

   Request Example:
   {
     "jobTitle": "مدير فرع",
     "fullName": "أحمد محمد محمود"
   }

   Response Example:
   {
     "data": {
       "id": "cm4employee123",
       "code": "EMP-918639",
       "fullName": "أحمد محمد محمود",
       "nationalId": "1234567890",
       "branchId": "cm4branch123",
       "jobTitle": "مدير فرع",
       "hireDate": "2025-01-01T00:00:00.000Z",
       "createdAt": "2026-08-19T14:45:00.000Z",
       "updatedAt": "2026-08-19T14:50:00.000Z",
       "deletedAt": null
     },
     "message": "Employee updated successfully"
   }

   Error Response (404): same as Get Employee By ID.

   Error Response (400 - national ID used by another employee):
   {
     "statusCode": 400,
     "message": "Employee with national ID 1234567890 already exists",
     "error": "Bad Request"
   }

5) Delete Employee
   Method: DELETE
   URL: /employees/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "Employee deleted successfully"
   }

   Error Response (404): same as Get Employee By ID.
