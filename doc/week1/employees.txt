Employees API Documentation
===========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see 00-overview.txt)
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

Every employee belongs to one branch.

Employee object (what "data" contains)
--------------------------------------
{
  "id": "cm4employee123",
  "code": "EMP-918639",              <-- generated by the server
  "fullName": "أحمد محمد",
  "nationalId": "1234567890",
  "branchId": "cm4branch123",
  "jobTitle": "مندوب مبيعات",
  "hireDate": "2025-01-01T00:00:00.000Z",
  "createdAt": "2026-08-19T14:45:00.000Z",
  "updatedAt": "2026-08-19T14:45:00.000Z",
  "deletedAt": null
}

---------------------------------------------------------
EMPLOYEES APIs
---------------------------------------------------------

1) Create Employee
   Method: POST
   URL: /employees/branch/:branchId

   Path Parameters:
   - branchId: required string (id from GET /branch)

   Validation Rules:
   - fullName: required string
   - nationalId: optional string (must be unique)
   - jobTitle: optional string
   - hireDate: optional ISO date string, e.g. "2025-01-01" or "2025-01-01T00:00:00.000Z"
   - code: do NOT send (generated by the server as "EMP-XXXXXX"; ignored if sent)

   Request Example:
   POST /employees/branch/cm4branch123
   {
     "fullName": "أحمد محمد",
     "nationalId": "1234567890",
     "jobTitle": "مندوب مبيعات",
     "hireDate": "2025-01-01"
   }

   Response Example (201):
   {
     "message": "Employee created successfully",
     "data": { ...employee object }
   }

   Error Response (404 - branch not found or deleted):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

   Error Response (409 - national ID used by an ACTIVE employee):
   {
     "statusCode": 409,
     "message": "nationalId already exists",
     "error": "Conflict",
     "code": "ALREADY_EXISTS",
     "field": "nationalId"
   }

   Error Response (409 - national ID belongs to a DELETED employee; national
   IDs stay reserved after delete and the employee is NOT restored):
   {
     "statusCode": 409,
     "message": "nationalId belongs to a deleted employee",
     "error": "Conflict",
     "code": "BELONGS_TO_DELETED",
     "field": "nationalId"
   }

2) Get All Employees By Branch
   Method: GET
   URL: /employees/branch/:branchId
   Description: All active (not deleted) employees of a branch, newest first.

   Response Example:
   {
     "message": "Employees returned successfully",
     "data": [ { ...employee object } ]
   }

   Error Response (404 - branch not found): same as Create.

2b) Get All Employees (optionally filtered by branch)   ** NEW **
   Method: GET
   URL: /employees
        /employees?branchId=cm4branch123
   Description: All active (not deleted) employees of ALL branches,
                newest first. Add ?branchId= to get only one branch's
                (same result as GET /employees/branch/:branchId).

   Query Parameters:
   - branchId: optional string (id of an existing branch). Must not be empty.
     Any other query parameter -> 400 "property <name> should not exist".

   Response Example:
   {
     "message": "All employees returned successfully",
     "data": [ { ...employee object }, { ...employee object } ]
   }

   Error Response (404 - branchId given but the branch is not found or deleted):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

   Error Response (400 - empty ?branchId=):
   { "statusCode": 400, "message": ["branchId should not be empty"], "error": "Bad Request", "code": "VALIDATION_FAILED", "field": "branchId" }

3) Get Employee By ID
   Method: GET
   URL: /employees/:id

   Response Example:
   {
     "message": "Employee returned successfully",
     "data": { ...employee object }
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "Employee with id cm4employee123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

4) Update Employee
   Method: PATCH
   URL: /employees/:id
   Description: Partial update. Fields (all optional): fullName, nationalId,
                jobTitle, hireDate.

   Request Example:
   {
     "jobTitle": "مدير فرع",
     "fullName": "أحمد محمد محمود"
   }

   Response Example:
   {
     "message": "Employee updated successfully",
     "data": { ...updated employee object }
   }

   Error Response (404): same as Get Employee By ID.
   Error Response (409 - national ID already used by an active or a deleted
   employee): same two bodies as Create.

5) Delete Employee
   Method: DELETE
   URL: /employees/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "Employee deleted successfully",
     "data": null
   }

   Error Response (404): same as Get Employee By ID.
