Inventory (Warehouse) API Documentation
=======================================

Base URL
--------
http://localhost:3000   (the backend runs on your machine with Docker, see README.md)

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see 00-overview.txt)
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

An inventory = a warehouse. Every inventory belongs to one branch.

Inventory object (what "data" contains)
---------------------------------------
{
  "id": "cm4inventory789",
  "name": "مخزن القاهره",
  "branchId": "cm4branch123",
  "address": "القاهره، المنطقة الصناعية",
  "createdAt": "2026-08-07T00:00:00.000Z",
  "updatedAt": "2026-08-07T00:00:00.000Z",
  "deletedAt": null
}

---------------------------------------------------------
INVENTORY APIs
---------------------------------------------------------

1) Create Inventory By Branch ID
   Method: POST
   URL: /inventory/branch/:branchId

   Path Parameters:
   - branchId: required string (id of an existing branch)

   Validation Rules:
   - name: required string, minimum 2 characters
   - address: required string, minimum 2 characters

   Request Example:
   POST /inventory/branch/cm4branch123
   {
     "name": "مخزن القاهره",
     "address": "القاهره، المنطقة الصناعية"
   }

   Response Example (201):
   {
     "message": "Inventory created successfully",
     "data": { ...inventory object }
   }

   Error Response (404 - branch not found or deleted):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

2) Get All Inventories By Branch ID
   Method: GET
   URL: /inventory/branch/:branchId
   Description: All active (not deleted) inventories of a branch, newest first.

   Response Example:
   {
     "message": "Inventories returned successfully",
     "data": [ { ...inventory object } ]
   }

   Error Response (404 - branch not found or deleted): same as Create.

2b) Get All Inventories (optionally filtered by branch)   ** NEW **
   Method: GET
   URL: /inventory
        /inventory?branchId=cm4branch123
   Description: All active (not deleted) inventories of ALL branches,
                newest first. Add ?branchId= to get only one branch's
                (same result as GET /inventory/branch/:branchId).

   Query Parameters:
   - branchId: optional string (id of an existing branch). Must not be empty.
     Any other query parameter -> 400 "property <name> should not exist".

   Response Example:
   {
     "message": "All inventories returned successfully",
     "data": [ { ...inventory object }, { ...inventory object } ]
   }

   Error Response (404 - branchId given but the branch is not found or deleted):
   {
     "statusCode": 404,
     "message": "Branch with id cm4branch123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

   Error Response (400 - empty ?branchId=):
   { "statusCode": 400, "message": ["branchId should not be empty"], "error": "Bad Request", "code": "VALIDATION_FAILED", "field": "branchId" }

3) Get Inventory By ID
   Method: GET
   URL: /inventory/:id

   Response Example:
   {
     "message": "Inventory returned successfully",
     "data": { ...inventory object }
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "Inventory with id cm4inventory789 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

4) Update Inventory
   Method: PATCH
   URL: /inventory/:id
   Description: Partial update (name and/or address). Both are required
                values, so null -> 400 (no nullable fields here).

   Request Example:
   {
     "name": "مخزن القاهره الرئيسي",
     "address": "القاهره، مدينة نصر"
   }

   Response Example:
   {
     "message": "Inventory updated successfully",
     "data": { ...updated inventory object }
   }

   Error Response (404): same as Get Inventory By ID.

5) Delete Inventory
   Method: DELETE
   URL: /inventory/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "Inventory deleted successfully",
     "data": null
   }

   Error Response (404): same as Get Inventory By ID.
