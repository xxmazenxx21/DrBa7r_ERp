Supplier API Documentation
==========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see 00-overview.txt)
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

NOTE: money fields are sent as numbers but returned as strings ("1500").

{
  "id": "cm4supplier123",

---------------------------------------------------------
SUPPLIER APIs
---------------------------------------------------------

1) Create Supplier
   Method: POST
   URL: /supplier

   Validation Rules:
   - name: required string
   - taxNumber: optional string
   - contactPerson: optional string
   - phone: optional string
   - email: optional string (must be a valid email)
   - openingBalance: optional number, minimum 0 (default 0)
   - code: do NOT send (generated by the server as "SUP-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "الشركة العالمية للتجارة",
     "taxNumber": "123-456-789",
     "contactPerson": "أحمد محمد",
     "phone": "01001234567",
     "email": "ahmed@example.com",
     "openingBalance": 1500.00
   }

   Response Example (201):
   {
     "message": "supplier created successfully",
     "data": { ...supplier object }
   }

   Error Response (400 - validation / unknown field):
   {
     "statusCode": 400,
     "message": ["name should not be empty", "name must be a string"],
     "error": "Bad Request",
     "code": "VALIDATION_FAILED",
     "field": "name"
   }

2) Get All Suppliers
   Method: GET
   URL: /supplier
   Description: All active (not deleted) suppliers, newest first.
                Empty list -> "data": []

   Response Example:
   {
     "message": "Suppliers returned successfully",
     "data": [ { ...supplier object } ]
   }

3) Get Supplier By ID
   Method: GET
   URL: /supplier/:id

   Response Example:
   {
     "message": "Supplier returned successfully",
     "data": { ...supplier object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "supplier does not exist",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

4) Update Supplier
   Method: PATCH
   URL: /supplier/:id
   Description: Partial update. Any field from Create (except code).

   Request Example:
   {
     "name": "الشركة العالمية للتجارة - محدث",
     "openingBalance": 2000.00
   }

   Response Example:
   {
     "message": "supplier updated successfully",
     "data": { ...updated supplier object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "supplier not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

5) Delete Supplier
   Method: DELETE
   URL: /supplier/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "supplier deleted successfully",
     "data": null
   }

   Error Response (404): same as Update.
