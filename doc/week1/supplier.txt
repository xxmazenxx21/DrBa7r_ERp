Supplier API Documentation
==========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication
--------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)

NOTE: openingBalance is sent as a number but returned as a string.
NOTE: GET responses here are NOT wrapped in "data" - see each endpoint.

---------------------------------------------------------
SUPPLIER APIs
---------------------------------------------------------

1) Create Supplier
   Method: POST
   URL: /supplier

   Validation Rules:
   - name: required string
   - taxNumber: optional string
   - contactPerson: optional string
   - phone: optional string
   - email: optional string (must be a valid email)
   - openingBalance: optional number, minimum 0 (default 0)
   - code: do NOT send (generated by the server as "SUP-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "الشركة العالمية للتجارة",
     "taxNumber": "123-456-789",
     "contactPerson": "أحمد محمد",
     "phone": "01001234567",
     "email": "ahmed@example.com",
     "openingBalance": 1500.00
   }

   Response Example (201):
   {
     "message": "supplier created successfully",
     "supplier": {
       "id": "cm4supplier123",
       "code": "SUP-260309",
       "name": "الشركة العالمية للتجارة",
       "taxNumber": "123-456-789",
       "contactPerson": "أحمد محمد",
       "phone": "01001234567",
       "email": "ahmed@example.com",
       "openingBalance": "1500",
       "createdAt": "2026-08-19T14:45:00.000Z",
       "updatedAt": "2026-08-19T14:45:00.000Z",
       "deletedAt": null
     }
   }

   Error Response (400 - validation, e.g. bad email):
   {
     "message": ["email must be an email"],
     "error": "Bad Request",
     "statusCode": 400
   }

2) Get All Suppliers
   Method: GET
   URL: /supplier
   Description: All active (not deleted) suppliers.

   Response Example - a plain ARRAY (empty [] when there are none):
   [
     {
       "id": "cm4supplier123",
       "code": "SUP-260309",
       "name": "الشركة العالمية للتجارة",
       "taxNumber": "123-456-789",
       "contactPerson": "أحمد محمد",
       "phone": "01001234567",
       "email": "ahmed@example.com",
       "openingBalance": "1500",
       "createdAt": "2026-08-19T14:45:00.000Z",
       "updatedAt": "2026-08-19T14:45:00.000Z",
       "deletedAt": null
     }
   ]


3) Get Supplier By ID
   Method: GET
   URL: /supplier/:id
   Description: Returns the supplier object directly (no "data" wrapper).

   Example Request:
   GET /supplier/cm4supplier123

   Response Example:
   {
     "id": "cm4supplier123",
     "code": "SUP-260309",
     "name": "الشركة العالمية للتجارة",
     "taxNumber": "123-456-789",
     "contactPerson": "أحمد محمد",
     "phone": "01001234567",
     "email": "ahmed@example.com",
     "openingBalance": "1500",
     "createdAt": "2026-08-19T14:45:00.000Z",
     "updatedAt": "2026-08-19T14:45:00.000Z",
     "deletedAt": null
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "supplier does not exist",
     "error": "Not Found"
   }

4) Update Supplier
   Method: PATCH
   URL: /supplier/:id
   Description: Partial update.

   Request Example:
   {
     "name": "الشركة العالمية للتجارة - محدث",
     "openingBalance": 2000.00
   }

   Response Example:
   {
     "message": "supplier updated successfully",
     "supplier": {
       "id": "cm4supplier123",
       "code": "SUP-260309",
       "name": "الشركة العالمية للتجارة - محدث",
       "taxNumber": "123-456-789",
       "contactPerson": "أحمد محمد",
       "phone": "01001234567",
       "email": "ahmed@example.com",
       "openingBalance": "2000",
       "createdAt": "2026-08-19T14:45:00.000Z",
       "updatedAt": "2026-08-19T14:50:00.000Z",
       "deletedAt": null
     }
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "supplier not found",
     "error": "Not Found"
   }

5) Delete Supplier
   Method: DELETE
   URL: /supplier/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "supplier deleted successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "supplier not found",
     "error": "Not Found"
   }
