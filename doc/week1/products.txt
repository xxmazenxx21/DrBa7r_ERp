Products API Documentation
==========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "message": "Unauthorized", "statusCode": 401 }
  - other roles         -> 403 { "message": "You do not have the required roles to access this resource", "error": "Forbidden", "statusCode": 403 }

Response shape: every success is { "message": "...", "data": ... }
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

NOTE: price fields are sent as numbers but returned as strings ("12.5"),
      with up to 4 decimals.

---------------------------------------------------------
PRODUCTS APIs
---------------------------------------------------------

1) Create Product
   Method: POST
   URL: /products

   Validation Rules:
   - name: required string
   - categoryId: required string (id from GET /categories)
   - primaryIteamUnitId: required string (id from GET /item-unit)  <-- spelling "Iteam" is real
   - itemType: required integer
   - retailPrice: required number, minimum 0
   - wholesalePrice: required number, minimum 0
   - bulkWholesalePrice: required number, minimum 0
   - barcode: optional string (must be unique)
   - costingMethod: optional integer
   - reorderLimit: optional number, minimum 0 (default 0)
   - hasExpiryDate: optional boolean (default false)
   - code: do NOT send (generated by the server as "PRD-XXXXXX"; ignored if sent)

   Request Example:
   {
     "barcode": "6221234567890",
     "name": "بيبسي 330 مل",
     "categoryId": "cm4category123",
     "primaryIteamUnitId": "cm4unit123",
     "itemType": 1,
     "costingMethod": 1,
     "retailPrice": 15.0,
     "wholesalePrice": 12.5,
     "bulkWholesalePrice": 10.0,
     "reorderLimit": 50,
     "hasExpiryDate": true
   }

   Response Example (201):
   {
     "message": "Product created successfully",
     "data": { ...product object }
   }

   Error Responses:
   - 400 validation error (missing / invalid / unknown fields)
   - 400 category or unit does not exist OR is deleted:
     { "statusCode": 400, "message": "categoryId does not exist", "error": "Bad Request" }
     { "statusCode": 400, "message": "primaryIteamUnitId does not exist", "error": "Bad Request" }
   - 409 barcode already used by another ACTIVE product:
     { "statusCode": 409, "message": "barcode already exists", "error": "Conflict" }
   - 409 barcode belongs to a DELETED product (the product is NOT restored):
     { "statusCode": 409, "message": "barcode belongs to a deleted product", "error": "Conflict" }

2) Get All Products
   Method: GET
   URL: /products
   Description: All active (not deleted) products, newest first, each with its
                category and primary unit.

   Response Example:
   {
     "message": "Products fetched successfully",
     "data": [
       {
         ...product object,
         "category": {
           "id": "cm4category123",
           "code": "category-839426",
           "name": "مشروبات",
           "createdAt": "2026-08-17T22:40:00.000Z",
           "updatedAt": "2026-08-17T22:40:00.000Z",
           "deletedAt": null
         },
         "primaryIteamUnit": {
           "id": "cm4unit123",
           "code": "unit-747728",
           "name": "قطعة",
           "createdAt": "2026-08-17T22:41:00.000Z",
           "updatedAt": "2026-08-17T22:41:00.000Z",
           "deletedAt": null
         }
       }
     ]
   }

3) Get Product By ID
   Method: GET
   URL: /products/:id
   Description: One active product with category, primary unit, and its
                ACTIVE stock records in every inventory (productInventories).

   Response Example:
   {
     "message": "Product fetched successfully",
     "data": {
       ...product object,
       "category": { ...same as in Get All },
       "primaryIteamUnit": { ...same as in Get All },
       "productInventories": [
         {
           "id": "cm4prodinv123",
           "productId": "cm4product123",
           "inventoryId": "cm4inventory789",
           "quantity": "100",
           "costPrice": "12.5",
           "deletedAt": null,
           "inventory": {
             "id": "cm4inventory789",
             "name": "مخزن القاهره",
             "branchId": "cm4branch123",
             "address": "القاهره، المنطقة الصناعية",
             "createdAt": "2026-08-07T00:00:00.000Z",
             "updatedAt": "2026-08-07T00:00:00.000Z",
             "deletedAt": null
           }
         }
       ]
     }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "Product with ID cm4product123 not found",
     "error": "Not Found"
   }

4) Update Product
   Method: PATCH
   URL: /products/:id
   Description: Partial update. Any field from Create (except code) is allowed.

   Request Example:
   {
     "name": "بيبسي 330 مل - سعر جديد",
     "retailPrice": 18.0
   }

   Response Example:
   {
     "message": "Product updated successfully",
     "data": { ...updated product object (no category / unit included) }
   }

   Error Responses:
   - 404 same as Get Product By ID
   - 400 new categoryId / primaryIteamUnitId does not exist or is deleted (same body as Create)
   - 409 barcode used by another active or deleted product (same bodies as Create)

5) Delete Product
   Method: DELETE
   URL: /products/:id
   Description: Soft delete (sets deletedAt).

   Response Example:
   {
     "message": "Product deleted successfully",
     "data": null
   }

   Error Response (404): same as Get Product By ID.
