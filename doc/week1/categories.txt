Categories API Documentation
============================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "message": "Unauthorized", "statusCode": 401 }
  - other roles         -> 403 { "message": "You do not have the required roles to access this resource", "error": "Forbidden", "statusCode": 403 }

Response shape: every success is { "message": "...", "data": ... }
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).


Category object (what "data" contains)
---------------------------------
{
  "id": "cm4category123",
  "code": "category-839426",          <-- generated by the server
  "name": "مشروبات",
  "createdAt": "2026-11-21T01:36:51.181Z",
  "updatedAt": "2026-11-21T01:36:51.181Z",
  "deletedAt": null
}

---------------------------------------------------------
APIs
---------------------------------------------------------

1) Create Category
   Method: POST
   URL: /categories

   Validation Rules:
   - name: required string
   - code: do NOT send (generated by the server as "category-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "مشروبات"
   }

   Response Example (201):
   {
     "message": "Category created successfully",
     "data": { ...category object }
   }

2) Get All
   Method: GET
   URL: /categories
   Description: All active (not deleted) records, newest first.

   Response Example:
   {
     "message": "All categories returned successfully",
     "data": [ { ...category object } ]
   }

3) Get By ID
   Method: GET
   URL: /categories/:id

   Response Example:
   {
     "message": "Category returned successfully",
     "data": { ...category object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "Category with id cm4category123 not found",
     "error": "Not Found"
   }

4) Update
   Method: PATCH
   URL: /categories/:id
   Description: Change the name.

   Request Example:
   {
     "name": "مشروبات باردة"
   }

   Response Example:
   {
     "message": "Category updated successfully",
     "data": { ...updated category object }
   }

   Error Response (404): same as Get By ID.

5) Delete
   Method: DELETE
   URL: /categories/:id
   Description: Soft delete (sets deletedAt). It disappears from lists and
                Get By ID returns 404. Products can no longer be created or
                moved to it (400 "...does not exist").

   Response Example:
   {
     "message": "Category deleted successfully",
     "data": null
   }

   Error Response (404): same as Get By ID.

   Error Response (400 - active products still use it):
   {
     "statusCode": 400,
     "message": "Category is used by 3 product(s) and cannot be deleted",
     "error": "Bad Request"
   }
   Move those products to another category first (PATCH /products/:id) or delete them.
   Deleted products do not count.
