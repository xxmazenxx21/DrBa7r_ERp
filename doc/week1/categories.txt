Categories API Documentation
============================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication
--------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)

NOTE: Delete is a HARD delete (record is removed permanently), and a category
that is used by products cannot be deleted.

---------------------------------------------------------
CATEGORIES APIs
---------------------------------------------------------

1) Create Category
   Method: POST
   URL: /categories

   Validation Rules:
   - name: required string
   - code: do NOT send (generated by the server as "category-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "مشروبات"
   }

   Response Example (201):
   {
     "data": {
       "id": "cm4category123",
       "code": "category-839426",
       "name": "مشروبات"
     },
     "message": "Category created successfully"
   }

2) Get All Categories
   Method: GET
   URL: /categories

   Response Example:
   {
     "data": [
       {
         "id": "cm4category123",
         "code": "category-839426",
         "name": "مشروبات"
       }
     ],
     "message": "All categories returned successfully"
   }

3) Get Category By ID
   Method: GET
   URL: /categories/:id

   Example Request:
   GET /categories/cm4category123

   Response Example:
   {
     "data": {
       "id": "cm4category123",
       "code": "category-839426",
       "name": "مشروبات"
     },
     "message": "Category returned successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "Category with id cm4category123 not found",
     "error": "Not Found"
   }

4) Update Category
   Method: PATCH
   URL: /categories/:id

   Request Example:
   {
     "name": "مشروبات باردة"
   }

   Response Example:
   {
     "data": {
       "id": "cm4category123",
       "code": "category-839426",
       "name": "مشروبات باردة"
     },
     "message": "Category updated successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "Category with id cm4category123 not found",
     "error": "Not Found"
   }

5) Delete Category
   Method: DELETE
   URL: /categories/:id
   Description: HARD delete.

   Response Example:
   {
     "data": null,
     "message": "Category with id cm4category123 removed successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "Category with id cm4category123 not found",
     "error": "Not Found"
   }

   Error Response (400 - products still use this category):
   {
     "statusCode": 400,
     "message": "Category is used by 3 product(s) and cannot be deleted",
     "error": "Bad Request"
   }
   Move those products to another category first (PATCH /products/:id).
   Note: soft-deleted products still count.
