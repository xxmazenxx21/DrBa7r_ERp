Item Unit API Documentation
===========================

Base URL
--------
Production:      https://drba7rerp-production.up.railway.app
Local (Docker):  http://localhost:3000

Authentication
--------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)

An item unit is a unit of measure (Kg, Carton, Piece...).

NOTE: Delete is a HARD delete (record is removed permanently), and a unit
that is used by products cannot be deleted.

---------------------------------------------------------
ITEM UNIT APIs
---------------------------------------------------------

1) Create Item Unit
   Method: POST
   URL: /item-unit

   Validation Rules:
   - name: required string
   - code: do NOT send (generated by the server as "unit-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "قطعة"
   }

   Response Example (201):
   {
     "data": {
       "id": "cm4unit123",
       "code": "unit-747728",
       "name": "قطعة"
     },
     "message": "ItemUnit created successfully"
   }

2) Get All Item Units
   Method: GET
   URL: /item-unit

   Response Example:
   {
     "data": [
       {
         "id": "cm4unit123",
         "code": "unit-747728",
         "name": "قطعة"
       }
     ],
     "message": "All item units returned successfully"
   }

3) Get Item Unit By ID
   Method: GET
   URL: /item-unit/:id

   Example Request:
   GET /item-unit/cm4unit123

   Response Example:
   {
     "data": {
       "id": "cm4unit123",
       "code": "unit-747728",
       "name": "قطعة"
     },
     "message": "ItemUnit returned successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "ItemUnit with id cm4unit123 not found",
     "error": "Not Found"
   }

4) Update Item Unit
   Method: PATCH
   URL: /item-unit/:id

   Request Example:
   {
     "name": "قطع"
   }

   Response Example:
   {
     "data": {
       "id": "cm4unit123",
       "code": "unit-747728",
       "name": "قطع"
     },
     "message": "ItemUnit updated successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "ItemUnit with id cm4unit123 not found",
     "error": "Not Found"
   }

5) Delete Item Unit
   Method: DELETE
   URL: /item-unit/:id
   Description: HARD delete. Returns the deleted unit.

   Response Example:
   {
     "data": {
       "id": "cm4unit123",
       "code": "unit-747728",
       "name": "قطع"
     },
     "message": "ItemUnit deleted successfully"
   }

   Error Response (404):
   {
     "statusCode": 404,
     "message": "ItemUnit with id cm4unit123 not found",
     "error": "Not Found"
   }

   Error Response (400 - products still use this unit):
   {
     "statusCode": 400,
     "message": "ItemUnit is used by 3 product(s) and cannot be deleted",
     "error": "Bad Request"
   }
   Change those products' primaryIteamUnitId first (PATCH /products/:id).
   Note: soft-deleted products still count.
