Item Unit API Documentation
===========================

Base URL
--------
http://localhost:3000   (the backend runs on your machine with Docker, see README.md)

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see 00-overview.txt)
Unknown fields in a body -> 400 "property <name> should not exist"
Delete is a SOFT delete (record hidden, kept in the database).

An item unit is a unit of measure (Kg, Carton, Piece...).

Item unit object (what "data" contains)
---------------------------------------
{
  "id": "cm4unit123",
  "code": "unit-747728",          <-- generated by the server
  "name": "قطعة",
  "createdAt": "2026-11-21T01:36:51.181Z",
  "updatedAt": "2026-11-21T01:36:51.181Z",
  "deletedAt": null
}

---------------------------------------------------------
APIs
---------------------------------------------------------

1) Create Item unit
   Method: POST
   URL: /item-unit

   Validation Rules:
   - name: required string
   - code: do NOT send (generated by the server as "unit-XXXXXX"; ignored if sent)

   Request Example:
   {
     "name": "قطعة"
   }

   Response Example (201):
   {
     "message": "ItemUnit created successfully",
     "data": { ...item unit object }
   }

2) Get All
   Method: GET
   URL: /item-unit
   Description: All active (not deleted) records, newest first.

   Response Example:
   {
     "message": "All item units returned successfully",
     "data": [ { ...item unit object } ]
   }

3) Get By ID
   Method: GET
   URL: /item-unit/:id

   Response Example:
   {
     "message": "ItemUnit returned successfully",
     "data": { ...item unit object }
   }

   Error Response (404 - not found or deleted):
   {
     "statusCode": 404,
     "message": "ItemUnit with id cm4unit123 not found",
     "error": "Not Found",
     "code": "NOT_FOUND",
     "field": null
   }

4) Update
   Method: PATCH
   URL: /item-unit/:id
   Description: Change the name.

   Request Example:
   {
     "name": "قطع"
   }

   Response Example:
   {
     "message": "ItemUnit updated successfully",
     "data": { ...updated item unit object }
   }

   Error Response (404): same as Get By ID.

5) Delete
   Method: DELETE
   URL: /item-unit/:id
   Description: Soft delete (sets deletedAt). It disappears from lists and
                Get By ID returns 404. Products can no longer be created or
                moved to it (400 "...does not exist").

   Response Example:
   {
     "message": "ItemUnit deleted successfully",
     "data": null
   }

   Error Response (404): same as Get By ID.

   Error Response (400 - active products still use it):
   {
     "statusCode": 400,
     "message": "ItemUnit is used by 3 product(s) and cannot be deleted",
     "error": "Bad Request",
     "code": "BAD_REQUEST",
     "field": null
   }
   Change those products' primaryItemUnitId first (PATCH /products/:id) or delete them.
   Deleted products do not count.

   Error Response (400 - used as another unit of an active product, Week 2):
   {
     "statusCode": 400,
     "message": "ItemUnit is used by 2 product unit(s) and cannot be deleted",
     "error": "Bad Request",
     "code": "BAD_REQUEST",
     "field": null
   }
   Delete those product units first (DELETE /product-units/:id, see
   doc/week2/product-units.txt). Units of deleted products do not count.
