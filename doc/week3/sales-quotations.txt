Sales Quotations API Documentation (عروض أسعار البيع)
====================================================

Base URL
--------
http://localhost:3000   (the backend runs on your machine with Docker, see README.md)

Authentication & access
-----------------------
All endpoints require:  Authorization: Bearer <access_token>   (see doc/week1/auth.txt)
Only SUPERADMIN can call them:
  - no / invalid token  -> 401 { "statusCode": 401, "message": "Unauthorized", "error": "Unauthorized", "code": "UNAUTHORIZED", "field": null }
  - other roles         -> 403 { "statusCode": 403, "message": "You do not have the required roles to access this resource", "error": "Forbidden", "code": "FORBIDDEN", "field": null }

Response shape: every success is { "message": "...", "data": ... }
Every error has { statusCode, message, error, code, field } (see doc/week1/00-overview.txt)
Unknown fields (also inside lines) -> 400 "property <name> should not exist"
Delete is a SOFT delete. Numbers are SENT as numbers and RETURNED as strings.
Dates are SENT as "YYYY-MM-DD" and RETURNED as "YYYY-MM-DDT00:00:00.000Z".

What is it?
-----------
Our prices for a CUSTOMER (العميل). A sales quotation has NO effect on stock
or money. It is the mirror of the purchase quotation (doc/week2/purchase-quotations.txt):
same header + lines, same statuses, same rules - with customerId instead of
supplierId and SQ numbers.

  - The server gives the number: SQ-2026-000001 (one counter per year).
  - The server computes EVERY total; you send quantities, prices and percents.
  - Status (الحالة) - QuotationStatus:
        DRAFT (مسودة) --> SENT (مُرسل) --> ACCEPTED (مقبول)
                                      \-> REJECTED (مرفوض)
        ACCEPTED --> CONVERTED (تم التحويل لفاتورة)   (only via convert-to-invoice, API 7)
    Only these moves are allowed; anything else -> 409 INVALID_STATUS.
  - Edit: only while DRAFT or SENT. Delete: any status except CONVERTED.
  - Selling price: you send unitPrice (suggest the product's retailPrice /
    wholesalePrice in the form). No price level per customer.

The brush example (Week 3 story)
--------------------------------
  5 cartons (12 brushes each) x 180, discount 5%, tax 14%:
    lineTotal 900 -> subTotal 900, discountValue 45, taxValue 119.70 (14% of 855),
    netTotal 974.70, code SQ-2026-000001

Header fields (Arabic label = what the screen shows)
----------------------------------------------------
  field                 Arabic           who      notes
  --------------------  ---------------  -------  ---------------------------------------------
  id                    -                server
  code                  رقم العرض         server   SQ-2026-000001 (year = quotationDate's year)
  quotationDate         تاريخ العرض       user     "2026-11-27" (required)
  validUntil            صالح حتى          user     optional, >= quotationDate; null clears
  status                الحالة            server   DRAFT at creation (change it with /status)
  customerId            العميل            user     an active customer (GET /customer)
  branchId              الفرع             user     an active branch
  warehouseId           المخزن            user     optional, must belong to branchId; null clears
  subTotal              الإجمالي          server
  discountPercent       نسبة الخصم %      user     optional, 0-100, max 2 decimals
  discountValue         قيمة الخصم        server   (or yours, if you send no discountPercent; max 2 decimals)
  taxPercent            نسبة الضريبة %    user     optional, 0-100 (e.g. 14)
  taxValue              قيمة الضريبة      server
  netTotal              الصافي            server
  convertedToInvoiceId  الفاتورة الناتجة   server   the sales invoice id, set by convert-to-invoice; null before
  notes                 ملاحظات           user     optional, max 500; null clears
  createdBy / createdDate      أنشأه / تاريخ الإنشاء   server (the logged-in user)
  modifiedBy / modifiedDate    عدّله / تاريخ التعديل   server
  isExpired             منتهي الصلاحية    server   true when validUntil has passed (read only)

Line fields (البنود)
-------------------
  field            Arabic            who      notes
  ---------------  ----------------  -------  ---------------------------------------------
  productId        الصنف              user     an active product (SERVICE products are allowed)
  itemUnitId       الوحدة             user     the primary unit or one of the product's units
                                              (GET /products/:productId/units)
  unitFactor       معامل الوحدة        server   pieces in one itemUnitId (carton = 12)
  quantity         الكمية             user     > 0, max 4 decimals, in itemUnitId
  unitPrice        سعر البيع للوحدة    user     >= 0, max 4 decimals, price of ONE itemUnitId
  discountPercent  نسبة خصم البند %    user     optional, 0-100   } send ONE of them,
  discountValue    قيمة خصم البند      user     optional, >= 0    } not both
  lineTotal        إجمالي البند        server   quantity x unitPrice - line discount
  notes            ملاحظات            user     optional, max 250

Totals
------
  lineTotal     = quantity x unitPrice - line discount            (4 decimals)
  subTotal      = sum of lineTotal                                (2 decimals)
  discountValue = subTotal x discountPercent / 100 (a percent above 0 wins;
                  otherwise the fixed discountValue you send)
  taxValue      = (subTotal - discountValue) x taxPercent / 100
  netTotal      = subTotal - discountValue + taxValue             (half-up rounding)

SALES QUOTATION APIs
---------------------------------------------------------

   URL: /sales-quotations

2) List
   Method: GET
   URL: /sales-quotations
   Description: PAGINATED, newest quotationDate first. Each item = the header
                + customer / branch / warehouse + "_count": { "lines": N } +
                isExpired. NO lines (open one quotation to see them).
   Query (all optional): customerId, branchId, status, dateFrom, dateTo
   (quotationDate, inclusive), search (part of the code, the customer name or
   the notes, any case), page, pageSize (1-100, default 20).

   Request Example:
   GET /sales-quotations?status=ACCEPTED&search=الشفاء&page=1&pageSize=20

   Response Example (200):
   {
     "message": "Sales quotations returned successfully",
     "data": {
       "items": [ { ...header, "code": "SQ-2026-000001", "status": "ACCEPTED",
                    "customer": { "id": "cmwykv6zq00002fn7p7rmrkus", "code": "CUS-709561", "name": "صيدلية الشفاء" },
                    "branch": {...}, "warehouse": {...}, "_count": { "lines": 1 }, "isExpired": false } ],
       "meta": { "page": 1, "pageSize": 20, "total": 1, "totalPages": 1 }
     }
   }
   Error: a bad filter (e.g. status=POSTED) or an unknown parameter -> 400 VALIDATION_FAILED.

3) Get one
   Method: GET
   URL: /sales-quotations/:id
   Response (200): { "message": "Sales quotation returned successfully", "data": { ...same object as Create } }
   Error (404): { "statusCode": 404, "message": "Sales quotation with id xxx not found", "error": "Not Found", "code": "NOT_FOUND", "field": null }

4) Update
   Method: PATCH
   URL: /sales-quotations/:id
   Description: Only while DRAFT or SENT. Any field from Create, all optional.
                "lines", when sent, REPLACES ALL the lines (send the full list).
                Not sent = the lines stay. Totals are always computed again.
                null clears validUntil / warehouseId / notes; null on other
                fields -> 400. A discountValue sent alone switches to a fixed
                discount (discountPercent becomes 0).

   Request Example:
   { "discountPercent": 10, "notes": "السعر شامل التوصيل" }

   Response (200): { "message": "Sales quotation updated successfully", "data": { ...quotation object } }
   Errors: same as Create, plus
   - 409 not DRAFT / SENT
     { "statusCode": 409, "message": "This quotation is ACCEPTED: only DRAFT or SENT quotations can be edited", "error": "Conflict", "code": "INVALID_STATUS", "field": "status" }

5) Change status
   Method: PATCH
   URL: /sales-quotations/:id/status
   Body: { "status": "SENT" }   (one of SENT, ACCEPTED, REJECTED)
   Allowed: DRAFT -> SENT, SENT -> ACCEPTED, SENT -> REJECTED.

   Response (200) - real response after DRAFT -> SENT:
   { "message": "Sales quotation status updated successfully", "data": { ...quotation object, "code": "SQ-2026-000001", "status": "SENT" } }

   Errors:
   - 409 move not allowed (e.g. DRAFT -> ACCEPTED)
     { "statusCode": 409, "message": "Can't change status from DRAFT to ACCEPTED (allowed: DRAFT -> SENT, SENT -> ACCEPTED or REJECTED)", "error": "Conflict", "code": "INVALID_STATUS", "field": "status" }
   - 400 another value (DRAFT, CONVERTED...)
     { "statusCode": 400, "message": ["status must be one of the following values: SENT, ACCEPTED, REJECTED"], "error": "Bad Request", "code": "VALIDATION_FAILED", "field": "status" }

6) Delete
   Method: DELETE
   URL: /sales-quotations/:id
   Description: Soft delete, any status EXCEPT CONVERTED.
   Response (200): { "message": "Sales quotation deleted successfully", "data": null }
   Error (409): { "statusCode": 409, "message": "A CONVERTED quotation can't be deleted", "error": "Conflict", "code": "INVALID_STATUS", "field": "status" }

7) Convert to invoice (تحويل لفاتورة)
   Method: POST
   URL: /sales-quotations/:id/convert-to-invoice
   Description: An ACCEPTED quotation becomes a DRAFT sales invoice
                (doc/week3/sales-invoices.txt) with the same customer, branch,
                lines (product, unit, quantity, unitPrice, line discounts,
                notes), header discount, tax and notes, in the DEFAULT currency
                (exchangeRate 1), no dueDate. The quotation becomes CONVERTED
                and convertedToInvoiceId points to the invoice; the invoice has
                "convertedFromQuotation": { "id", "code" }. All or nothing: if
                it fails, the quotation stays ACCEPTED, no invoice is made and
                no SI number is used. Clicking twice can't make two invoices
                (the second gets 409). NO stock effect: the invoice is a
                normal DRAFT; edit it if needed (dueDate, paidAmount...) and
                then POST it (that is when the goods leave the warehouse).

   Body:
   - paymentType: required, CASH (paidAmount = netTotal) or CREDIT (paidAmount 0)
   - invoiceDate: required, "2026-11-27"
   - warehouseId: optional; the quotation's warehouse is used if not sent;
                  REQUIRED when the quotation has none. Must belong to the
                  quotation's branch. null -> 400.
   Anything else (currencyId, lines, discounts...) -> 400 "property X should not exist".

   Request Example:
   POST /sales-quotations/cmwyn2drr00102emp438n5v40/convert-to-invoice
   { "paymentType": "CREDIT", "invoiceDate": "2026-11-27" }

   Response Example (201) - real response (shortened: the two objects are the
   full quotation object above and the full invoice object of sales-invoices.txt):
   {
     "message": "Sales quotation converted to invoice successfully",
     "data": {
       "quotation": {
         "id": "cmwyn2drr00102emp438n5v40",
         "code": "SQ-2026-000001",
         "status": "CONVERTED",
         "netTotal": "974.7",
         "convertedToInvoiceId": "cmwyn2dug00132empr4yegd7y",
         "modifiedBy": "1aa6879a-9814-4df0-b29f-e66fae89f6a6",
         "modifiedByUser": { "id": "1aa6879a-9814-4df0-b29f-e66fae89f6a6", "username": "admin" },
         ...the other quotation fields, customer, branch, warehouse, lines, "isExpired": false
       },
       "invoice": {
         "id": "cmwyn2dug00132empr4yegd7y",
         "code": "SI-2026-000001",
         "invoiceDate": "2026-11-27T00:00:00.000Z",
         "dueDate": null,
         "status": "DRAFT",
         "paymentType": "CREDIT",
         "currencyId": "cmwyn2d7g00002empbnekajdb",
         "exchangeRate": "1",
         "subTotal": "900",
         "discountPercent": "5",
         "discountValue": "45",
         "taxPercent": "14",
         "taxValue": "119.7",
         "netTotal": "974.7",
         "paidAmount": "0",
         "remainingAmount": "974.7",
         "totalCost": "0",
         "notes": "السعر شامل التوصيل",
         "currency": { "id": "cmwyn2d7g00002empbnekajdb", "code": "EGP", "name": "جنيه مصري", "symbol": "ج.م" },
         "convertedFromQuotation": { "id": "cmwyn2drr00102emp438n5v40", "code": "SQ-2026-000001" },
         "lines": [ { "unitFactor": "12", "quantity": "5", "baseQuantity": "60", "unitPrice": "180",
                      "lineTotal": "900", "stockUnitCost": "0", "lineCost": "0", ... } ],
         "grossProfit": null,
         ...the other invoice fields, customer, branch, warehouse, users
       }
     }
   }

   Errors:
   - 409 not ACCEPTED (DRAFT, SENT, REJECTED, or converted already)
     { "statusCode": 409, "message": "This quotation is CONVERTED: only an ACCEPTED quotation can be converted to an invoice", "error": "Conflict", "code": "INVALID_STATUS", "field": "status" }
     (a DRAFT one: "This quotation is DRAFT: only an ACCEPTED quotation can be converted to an invoice")
   - 404 quotation missing or deleted
     { "statusCode": 404, "message": "Sales quotation with id xxx not found", "error": "Not Found", "code": "NOT_FOUND", "field": null }
   - 400 no warehouse anywhere
     { "statusCode": 400, "message": ["warehouseId is required: the quotation has no warehouse"], "error": "Bad Request", "code": "VALIDATION_FAILED", "field": "warehouseId" }
   - 400 warehouse of another branch
     { "statusCode": 400, "message": "warehouseId must belong to branchId", "error": "Bad Request", "code": "BAD_REQUEST", "field": "warehouseId" }
   - 400 warehouse missing or deleted
     { "statusCode": 400, "message": "warehouseId does not exist", "error": "Bad Request", "code": "DOES_NOT_EXIST", "field": "warehouseId" }
   - 400 a line's product was deleted since the quotation (N = the line, from 0)
     { "statusCode": 400, "message": "productId does not exist", "error": "Bad Request", "code": "DOES_NOT_EXIST", "field": "lines.1.productId" }
   - 400 the customer / branch was deleted, a line's unit is no longer defined,
     no default currency: same bodies as POST /sales-invoices
   - 400 bad body
     { "statusCode": 400, "message": ["paymentType must be one of the following values: CASH, CREDIT"], "error": "Bad Request", "code": "VALIDATION_FAILED", "field": "paymentType" }

   After the convert:
   - the quotation can't be edited (409) or deleted (409 "A CONVERTED quotation can't be deleted");
   - GET /sales-quotations/:id has "status": "CONVERTED" and "convertedToInvoiceId";
     open the invoice with GET /sales-invoices/<convertedToInvoiceId>;
   - GET /sales-invoices/:id has "convertedFromQuotation": { "id", "code": "SQ-2026-000001" }.

Suggested Arabic messages
-------------------------
  INVALID_STATUS                              لا يمكن تنفيذ العملية في حالة المستند الحالية
  VALIDATION_FAILED + lines                   يجب إضافة بند واحد على الأقل
  VALIDATION_FAILED + lines.N.discountValue   أدخل نسبة الخصم أو قيمة الخصم فقط، وليس الاثنين
  BAD_REQUEST + lines.N.itemUnitId            هذه الوحدة غير معرفة لهذا الصنف
  DOES_NOT_EXIST + customerId                 العميل غير موجود أو محذوف
  DOES_NOT_EXIST + lines.N.productId          الصنف غير موجود أو محذوف
  VALIDATION_FAILED + warehouseId (convert)   اختر المخزن: عرض السعر ليس له مخزن
  BAD_REQUEST + warehouseId                   المخزن يجب أن يكون تابعًا لنفس الفرع
  BAD_REQUEST + validUntil                    تاريخ الصلاحية يجب أن يكون بعد تاريخ العرض
  BAD_REQUEST + discountValue                 قيمة الخصم أكبر من المبلغ
